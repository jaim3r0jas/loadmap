# What's new

Every release of the loadmap packages, newest first: what each one added and what it fixed. The packages share one
version, and this site documents the latest, loadmap %VERSION% with language %LANGUAGE%: it is published with each
release, so a feature you read about here is on npm.

The packages' own `CHANGELOG.md` files say the same, one package at a time. A file of the language keeps reading the
same under every later version ([Versions](/language/errors/#versions)).
