Keeping a key sealed says what to do when it cannot: an error a `KeyVault` throws may carry `links`
(`{ href, label }[]`, https), shown after its message. The docs' editor uses them when the GitHub token may not make
`loadmap-keys`: a link to make the repository on GitHub, private, then the same press keeps the key.
